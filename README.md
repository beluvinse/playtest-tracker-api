# PlaytestTracker.Api

A backend learning project built with ASP.NET Core.

The goal of this project is to practice building REST APIs, organizing backend logic, handling HTTP responses, and later integrating databases, authentication, testing, and deployment.

## Current features
- Retrieve all bug reports
- Retrieve a bug report by ID
- In-memory data storage
- Basic HTTP status handling

## Tech
- C#
- .NET 8
- ASP.NET Core Web API

## Planned
- Create, update, and delete bug reports
- DTOs and validation
- Entity Framework Core
- SQL database
- Authentication and authorization
- Automated tests
- Docker
- Deployment
